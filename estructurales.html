Etiquetas Estructurales

<header>

Definición: Define la cabecera de una página o sección.

Sintaxis:

<header>
    <h1>Título</h1>
</header>

Ejemplo:

Mi página

Uso: Se utiliza para encabezados principales.

Buenas prácticas: Solo usar uno principal por sección.

<nav>

Definición: Define un menú de navegación.

Sintaxis:

    <nav>
        <a href="#">Inicio</a>
        <a href="#">Contacto</a>
    </nav>

Ejemplo:

Inicio | Servicios | Contacto
