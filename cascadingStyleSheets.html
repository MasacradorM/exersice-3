CSS (Cascading Style Sheets)

Selectores

Definición: Usados para seleccionar los elementos a los que se aplica un estilo (etiquetas, clases y id).

Sintaxis:

    img {
        width: 30%;
        height: 20svh;
    }
    .imageBlog {
        width: 70%;
    }
    #contenedor {
        background-color: red;
    }

Sin simbolo: Para aplicar estilos a un tipo de etriqueta.

Con el punto: Para aplicar estilos a una clase.

Con el símbolo #: Para aplicar estilos a un elemento.

Declaraciones

Definición: Las declaraciones en CSS son instrucciones que indican qué estilo se aplicará a un elemento..


    pre{

    background:#222;
    color:#fff;
    padding:10px;
    width: 20%;
    height: 20svh;
    margin-top: 5dvh;

    }

background: Color de fondo.

color: Color del texto.

padding: Espacio entre el contenido y el borde.

width: Ancho del contenedor.

height: Alto del contenedor.

margin-top: Espacio entre el contenido y el borde superior.
