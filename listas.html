Etiquetas de Listas

<ul>

Definición: Crea una lista desordenada.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ejemplo:

  • HTML
  • CSS
  • JavaScript

<ol>

Definición: Crea una lista ordenada.

<ol>
    <li>Abrir el editor</li>
    <li>Crear archivo HTML</li>
    <li>Guardar</li>
</ol>

Ejemplo:

  1. Abrir el editor
  2. Crear archivo HTML
  3. Guardar

<li>

Definición: Define un elemento dentro de una lista.

<ol>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
    <li>Elemento 3</li>
</ol>

Ejemplo:

  1. Elemento 1
  2. Elemento 2
  3. Elemento 3

Uso: Siempre debe ir dentro de ul u ol.
