<form>: Define un formulario HTML que permite al usuario ingresar y enviar información.

<label>: Representa una etiqueta de texto que describe el campo del formulario.

<input>: Permite crear campos donde el usuario puede ingresar datos.

type: Define el tipo de dato que se ingresará en el campo (por ejemplo: texto, correo, número, etc.).

required: Indica que el campo es obligatorio y debe ser completado antes de enviar el formulario.

placeholder: Muestra un texto de ayuda dentro del campo indicando qué información debe ingresar el usuario.

class: Permite aplicar estilos CSS o utilizar clases de Bootstrap para mejorar la apariencia del formulario.

name: Identifica el campo del formulario cuando los datos son enviados al servidor.

id: Identificador único del elemento que permite seleccionarlo con CSS o JavaScript.

<button>: Crea un botón que permite enviar o ejecutar una acción dentro del formulario.

type="password": Permite ingresar contraseñas. Los caracteres que el usuario escribe se muestran ocultos para proteger la información.

type="date": Permite seleccionar una fecha mediante un calendario integrado en el navegador.

type="checkbox": Permite seleccionar una o varias opciones dentro de una lista.
