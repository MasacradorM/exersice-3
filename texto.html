Etiquetas de Texto

<h1> - <h6>

Definición: Se utilizan para títulos y subtítulos.

Sintaxis:

    <h1>Título principal</h1>
    <h2>Subtítulo</h2>

Ejemplo:

Título Principal

Subtítulo

Buenas prácticas: Usar solo un h1 por página.

<p>

Definición: Define un párrafo.

<p>Este es un párrafo</p>

Ejemplo:

Este es un ejemplo de párrafo en HTML.

<strong>

Definición: Muestra texto en negrita con importancia.

<strong>Texto importante</strong>

Ejemplo:

Este texto es importante

<em>

Definición: Se utiliza para enfatizar texto.

<em>Texto enfatizado</em>

Ejemplo:

Este texto tiene énfasis
